# 无信号载荷感知的 MHE + NMPC:抓取—机动—投放

> 写给想快速理解本方法的读者(导师 / 组内同学 / 新人),假设读者懂四旋翼与 MPC/MHE 的基本概念。
> 本文只讲原理与数据流,不涉及代码细节;描述的是 2026-09-17 的默认配置。
> English version: [算法简介_无信号载荷感知MHE-NMPC-EN.md](算法简介_无信号载荷感知MHE-NMPC-EN.md)。

## 1. 要解决什么问题

四旋翼抓起一个**质量和偏心都未知**的箱子,带着它做高机动 8 字飞行(约 4 m/s),然后把箱子投下。

难点在于,**控制器和估计器事先什么都不知道**:

- 不知道箱子多重、挂偏了多少;
- 也收不到"已经吸上"或"已经脱落"的通知。

而载荷一变,飞机的动力学同时变了三样:

| 变化         | 后果                                    |
| ------------ | --------------------------------------- |
| 总质量变大   | 悬停推力算错,高度掉或冲                 |
| 质心偏移     | 推力不再穿过质心,产生一个常值的扭转力矩 |
| 转动惯量变大 | 同样的力矩转得更慢,姿态响应变迟钝       |

再加上一条安全要求:**发出投放指令不等于箱子真的掉了**。夹爪可能卡住,箱子可能延迟脱离,
也可能不发指令就意外掉了。控制器不能凭指令就认定自己已经空载。

**本方法的目标**:只用飞机自身的测量,在线估出载荷,让控制器随时用上正确的模型;
并且只在有物理证据时,才认定"载荷已经没了"。

## 2. 整体思路

系统分两层,各自按固定周期滚动更新:

```
 电机转速 ─┐
           ├─► MHE(估计器,10 Hz) ──载荷估计──► NMPC(控制器,20 Hz) ──角速度 + 推力──► 飞控
 里程计 ───┘                                   ▲
                                               └── 里程计(当前状态)
```

- **MHE**(滑动时域估计):每 0.1 s 看一遍最近 2 秒的飞行数据,反推出"载荷是多少"。
- **NMPC**(模型预测控制):每 0.05 s 用最新的载荷估计更新自己的模型,预测未来 1 秒,
  算出最优控制量。
- **信息只单向流动**,从 MHE 到 NMPC。MHE 不看控制器发了什么指令,也不接收任何吸附或投放事件。

## 3. 测量量:从电机转速得到"实际受力"

MHE 需要知道飞机每一时刻实际受到的推力和力矩。它们不取自控制器的指令,而是**由电机转速直接算出**:

- 单个旋翼推力 `F_i = k · ω_i²`,总推力 `T = Σ F_i`;
- 三轴力矩由各旋翼推力乘以力臂(以及旋翼的反扭矩系数)算出。

**为什么不能用控制器的指令?** 指令本身是按"当前的质量估计"算出来的。质量一旦估错,
指令也跟着错,估计器就会拿错的输入去"印证"错的估计,永远发现不了问题。电机转速是执行器
实际转出来的结果,与估计值无关,这样才能真正检验估计对不对。

**还要做区间平均**:电机数据是 250 Hz,而 MHE 每 0.1 s 才取一次。如果只取采样时刻最近的
那一帧(点采样),飞机振荡时会严重混叠,和这 0.1 s 内真正作用的力差得很远。所以每一步用的,
是这 0.1 s 内全部电机样本算出的**平均推力和平均力矩**。

## 4. 载荷怎么描述:质量 + 一阶质量矩

载荷只用两个量描述:

- **总质量 m**(机体加载荷);
- **一阶质量矩 s = m_P · r_xy**:载荷质量乘以它的水平偏心(2 维)。

其余与载荷有关的量,都由这两个量代数推出:

设载荷为质点,它相对机体质心的位置为 `r = [r_x, r_y, r_z]`(r_xy 为水平分量,r_z 为竖直分量),
m_B 为空机质量:

```
载荷质量          m_P  = m − m_B
复合质心水平偏移  c_xy = m_P · r_xy / m = s / m          (相对机体质心)
约化质量          μ    = m_B · m_P / m
惯量增量          ΔJ   = μ · (|r|² I₃ − r rᵀ)            (绕复合质心,精确形式)
```

本方法对 ΔJ 只保留主项和耦合项:

```
ΔJ_xx ≈ ΔJ_yy ≈ μ · r_z²                                 (略去 μ·r_y²、μ·r_x²,约 2%)
ΔJ_xz ≈ −μ · r_x · r_z = −(m_B / m) · s_x · r_z
ΔJ_yz ≈ −μ · r_y · r_z = −(m_B / m) · s_y · r_z
ΔJ_zz ≈ 0                                                 (略去 μ·|r_xy|²)
```

- 竖直偏移 r_z 由夹爪几何给定,视为已知,不在线估计(从推力—力矩数据里本来也观测不到)。
- 所有保留项都只需要 m 和 s,不需要把 m_P 与 r_xy 分开;载荷自身的转动惯量忽略不计。
- MHE 的模型用了上面的对角项和耦合项;NMPC 的模型只用对角项 ΔJ_xx、ΔJ_yy。

**为什么估 s,而不直接估偏心 r_xy?**

- 箱子掉了以后 `m_P → 0`,偏心 `r_xy` 变成 0/0,没有定义;而 `s = m_P · r_xy` 自然趋于 0,
  始终有定义。
- 从飞行数据里,载荷质量和偏心**本来就分不开**,能看出来的只有两者的乘积
  (偏心力矩正比于 m_P · r_xy)。直接估 s,估的正好是能观测到的那部分。
- 有偏心时,转动方向的数据会携带大量关于质量的信息(约 94% 的质量信息来自转动),
  把 s 放进模型,质量本身也估得更准。

## 5. MHE:每个周期怎么更新载荷估计

### 5.1 滑动窗口

MHE 始终维护最近 **20 步、共 2 秒**的数据窗口。每个周期做四件事:

1. 把最新一步的测量(位置、速度、姿态、角速度)和区间平均后的推力、力矩放进窗口;
2. 把最老的一步移出窗口;
3. 在整个窗口上重新求解一次优化问题;
4. 取解在**窗口末端(即当前时刻)**的 m 和 s,作为本周期的估计。

窗口是滑动的,所以估计**逐帧连续更新**:载荷一变,新数据一帧帧进来,估计随之爬升,
不需要等窗口填满。

### 5.2 优化问题

在窗口内,把"飞机状态 + m + s"都当作未知量,找一组最能解释这 2 秒观测的值:

```
min   到达代价(窗口起点与上一次估计的偏差)
    + Σ 测量残差²(模型预测的状态 − 实测状态)
    + Σ 过程噪声²(允许模型与真实动力学之间存在的小偏差)

s.t.  刚体动力学(推力、力矩为已知输入;质量、质心偏移、惯量都由 m 和 s 生成)
      m 和 s 在窗口内为常数
      m ≥ 0.95 × 空机质量(物理下界)
```

几个关键设计:

**① 测量噪声权重**:覆盖全部 13 个测量状态(质量和一阶矩没有直接测量,推力、力矩是已知输入,
都不在测量残差里)。权重取 `1/σ²`,σ 是按融合后状态估计的典型精度设定的量级,不是实测值。

| 测量量     | 维数 | 噪声标准差 σ  | 权重 1/σ² |
| ---------- | ---- | -------------- | ----------- |
| 位置       | 3    | 0.02 m         | 2500        |
| 速度       | 3    | 0.05 m/s       | 400         |
| 姿态四元数 | 4    | 0.01(约 1.1°) | 10⁴        |
| 角速度     | 3    | 0.02 rad/s     | 2500        |

**② 过程噪声权重**:只作用在 13 个物理状态上。m 和 s 在窗口内是常数,不受过程噪声驱动
(参数随机游走默认关闭)。

| 状态       | 维数 | 权重 | 等效 σ = 1/√权重 |
| ---------- | ---- | ---- | ------------------ |
| 位置       | 3    | 10⁴ | 0.01 m             |
| 速度       | 3    | 10⁴ | 0.01 m/s           |
| 姿态四元数 | 4    | 10⁵ | 0.0032             |
| 角速度     | 3    | 10³ | 0.032 rad/s        |

- 过程噪声整体比测量噪声**更紧**(角速度一项除外)。含义是"除了载荷未知,模型结构是对的":
  优化器只能靠调整 m 和 s 去解释观测到的加速度和角加速度,不能把误差随意推给过程噪声。
- 速度这一项最紧(比测量权重大 25 倍),因为质量主要通过 `T/m` 影响速度。
- 角速度这一项故意放松,因为转动动力学里的陀螺耦合项数值上更敏感,留些余地避免病态。

**③ 到达代价权重**:共 16 维(13 个物理状态 + m + s 的 2 维)。先验均值每个周期取上一窗口解中
第 2 步的状态,也就是窗口前移一步后的新起点,让估计在时间上保持连贯。

| 状态       | 维数 | 权重 | 等效 σ   |
| ---------- | ---- | ---- | --------- |
| 位置       | 3    | 10³ | 0.032 m   |
| 速度       | 3    | 10³ | 0.032 m/s |
| 姿态四元数 | 4    | 10⁴ | 0.01      |
| 角速度     | 3    | 10² | 0.1 rad/s |
| 质量 m     | 1    | 0.1  | 约 3.2 kg |
| 一阶矩 s   | 2    | 100  | 0.1 kg·m |

- 物理状态的权重比过程噪声低一个数量级,只做中等强度的锚定。
- 质量几乎不给先验:抓取、投放造成的质量阶跃,大约一个窗口就能重新收敛,估计也不会变成
  先验的回声。(不直接设为 0,是为了在激励不足时保持数值上的正定。)
- 一阶矩只给很弱的锚。收紧可以抑制小载荷时 s 被估大,放松则让投放后 s 更快归零,
  这里取的是两者的折中。

**④ 求解初值来自窗口竖直力平衡**,而不是空机质量:

```
m_seed = Σ_j T_j·cosθ_j / [ N·(g + ā_z) ]        j 遍历窗口内的 N 步

cosθ_j:推力方向在世界系竖直方向上的投影(由姿态四元数算出)
ā_z  :窗口内竖直加速度的平均值(由窗口两端的竖直速度差除以窗口时长得到)
```

即"窗口内的平均竖直推力分量 ÷ (重力 + 平均竖直加速度)"。用整段窗口而不是单帧,是为了平掉
噪声和机动引起的波动。几道保护:窗口必须攒满、平均推力不低于 1 N(确实在飞)、四元数正常、
分母大于 `0.5·N·g`(排除接近自由落体的窗口);不满足就退回瞬时的 `T/g`,再不行才退回空机质量
并告警。

⚠️ 这个值只进**求解初值**和到达代价的先验均值,而质量维的到达代价权重只有 0.1、几乎不进代价
函数,所以它影响的是收敛快慢,不是最优解本身——它是 initial guess,不是 prior。一阶矩 s 一律
从 0 起步。

### 5.3 出错时怎么自救(重锚)

如果估计器陷进错误的解,就用推力平衡重新给 m 定初值,把 s 清零,重新开始。触发条件有两个:

1. 连续 5 次求解失败;
2. 飞行平稳时,s 连续 1 秒超过物理上可能的最大值(最大载荷 × 最大偏心)。这说明求解虽然
   "成功",结果在物理上却不可能。

### 5.4 每个周期输出什么

每个周期,MHE 把以下内容**打包成一帧**发给 NMPC。一帧里的数值来自同一次求解,
不会出现"新质量配旧惯量"这种物理上不存在的组合:

- 质量 m、一阶矩 s,以及由它们推出的质心偏移 c、惯量增量 ΔJ;
- **空载置信度**(0~1):综合质量、一阶矩、惯量三方面的证据,表示"现在没有载荷"的可信程度;
- **健康标记**和**解的年龄**:本帧是否可信,距上一次成功求解过了多久。

### 5.5 质量突变时怎么加速收敛(事件降权)

**为什么需要**:窗口内 m 和 s 是常数。载荷刚变的时候,窗口里同时装着变化前后的数据,
两边互相拉扯,优化器只能给一个折中值,要等旧数据完全滑出窗口(2 秒)才收敛到位。

**怎么发现突变(无外部信号)**:对电机反算的推力 T 维护一条慢基线(时间常数 3 秒)。
先要求 T 贴着基线一段时间,检测器才算预热完成;之后只要 T 与基线的偏差超过阈值
(约 4.4 N = 1.5 × g × 载荷包线)并连续 2 帧,就记下**首次越阈的那一帧**作为事件帧。
T 低于基线表示载荷没了,高于基线表示上了货。

**怎么降权**:只要事件帧还在窗口里,就把**事件之前**那些步的测量残差权重和过程噪声权重
整体乘以 10⁻⁴,事件之后的步保持名义权重。于是旧数据几乎不再对 m 和 s 施加拉力,
估计一两帧内就能跳到新值。事件随窗口滑出后,权重自动恢复。

几个细节:

- 用**相对缩放**而不是直接置零:名义权重是 10³~10⁵,乘 10⁻⁴ 后还是 0.1~10 的良态数值,
  不会让子问题病态,同时又比事件后的步小四个数量级,足以让新数据主导。
- **不清空窗口**:物理状态部分照常暖启动,不必等窗口重新攒满。
- 窗口起点的**到达代价不降权**:物理状态的锚定保持不变,而质量方向的锚本来就只有 0.1,
  不构成拖累。

## 6. 载荷状态判定:什么时候算"带上了",什么时候算"没了"

估计器自己维护一个"空载 / 带载"状态,完全不依赖外部事件。

**判定为带载**:载荷质量持续为明显的正值。推力残差出现突变时,还会按 5.5 节的做法暂时降低
窗口内旧数据的权重,让估计更快跟上变化。

**判定为已卸载**:需要多方证据,任何单一证据都不够。证据有三类:

- **一阶矩塌陷**:确认带载后,在飞行平稳的时段记录一个"带载时的 |s|"作为基准,
  **记下后就冻结不再更新**;之后如果 |s| 降到基准的 30% 以下并持续一段时间,算一票。
  基准必须冻结,否则会被机动造成的虚高值污染。
- **质量回落**:载荷质量持续低于 30 g。
- **推力残差**:推力突然下降。

另外,**估计不健康时一律不做判定**。

**为什么这么谨慎?** 实测发现,8 字机动本身引起的推力残差,可以比一个小载荷真实掉落引起的
还大;高机动时质量估计也会短暂偏低。只看单一信号,分不清"在做机动"和"真掉了"。

## 7. NMPC:每个周期怎么用上载荷估计

### 7.1 载荷模型的更新

每个控制周期(0.05 s),NMPC 做三件事:

1. 读取 MHE 的最新一帧。如果这一帧不健康,或者已经超过 0.35 s 没更新,
   **就保持上一个安全模型不变**;
2. 对 m 和 s 做低通滤波和变化速率限制,避免估计的跳动直接冲击控制器;
3. 计算质心偏移 `c = s/m` 和惯量增量 `ΔJ`,写进预测模型。

**吸附瞬间的惯量兜底**:刚发出吸附指令时,MHE 还来不及估出载荷。此时先按"最大可能载荷"
给惯量一个安全地板;等 MHE 持续给出带载证据,再在 0.5 s 内平滑交接给 MHE 估出的惯量。

### 7.2 预测模型里载荷怎么起作用

```
平动:  v̇ = (R·[0, 0, T] − k_d·v) / m − g
转动:  ω̇ = (τ + [−c_y·T, +c_x·T, 0] − ω × Jω) / (J + ΔJ)
```

- **质量 m** 决定同样的推力能产生多大加速度;
- **质心偏移 c** 产生偏心力矩 `c × T`,NMPC 因此会自动给出抵消它的配平力矩;
- **惯量增量 ΔJ** 让模型知道飞机转得更慢了。

代价函数里的输入参考也随载荷变化:参考推力取 `m·g`,参考力矩取上面的配平力矩。
否则代价函数会一直把输入往"空机悬停值"拽,造成稳态偏差。

### 7.3 求解与执行

- 每个周期求解一次:预测未来 1 秒(20 步),在推力和力矩的物理上限内找最优输入;
- 下发给飞控的是**机体角速度 + 推力**(推力按电机模型换算成油门),以 50 Hz 沿预测轨迹
  插值发送;
- **惯量补偿**:飞控的角速度环是按空机整定的,带载后响应会变慢。NMPC 把"期望角速度与当前
  角速度之差"按 `(J + ΔJ) / J` 放大后再下发(上限 5 倍),效果等同于把角速度环的增益相应调大,
  但不修改飞控参数。

### 7.4 投放时控制器怎么做

- 发出投放指令后,控制器**不会立刻清除载荷模型**。它等 MHE 的空载置信度连续 1 秒超过 0.9,
  才确认卸载,切换回空机模型;                                                                                                                                                                     
- 如果 12 秒内拿不到足够证据,就进入**未决状态**:保留当前模型,用 3 秒平滑减速到悬停,在低动态下重新收集证据;
- 没有指令的意外脱落,只要估计器判定空载、置信度达标,同样会被确认。

## 8. 一次任务中各个量怎么变化

| 阶段            | 实际发生了什么          | MHE 的估计                                 | NMPC 的模型与行为                                        |
| --------------- | ----------------------- | ------------------------------------------ | -------------------------------------------------------- |
| 空机飞行        | 无载荷                  | m ≈ 空机质量,s ≈ 0,空载置信度高          | 空机模型                                                 |
| 下降、吸附      | 箱子吸上,但还被地面托着 | m 基本不变                                 | 发出吸附指令,惯量先抬到安全地板                          |
| 吊起离地        | 箱子离地,开始真正承重   | m 爬升到带载值,s 出现,空载置信度下降       | 质量、偏心随估计更新;确认带载后,惯量交接给 MHE           |
| 8 字机动        | 持续带载飞行            | m、s 保持在带载值附近(机动中 s 会小幅漂动) | 按带载模型跟踪,自动输出配平力矩                          |
| 投放            | 箱子脱离                | m 回落,s 归零,空载置信度升高               | 置信度持续达标后,切回空机模型                            |
| 卡住 / 意外脱落 | 指令与实际不一致        | 跟随实际的物理变化                         | 卡住:进入未决状态并悬停,不清模型;意外脱落:由证据自主确认 |

## 9. 实现了什么(仿真验证)

以下结果全部来自 PX4 软件在环仿真(Gazebo)。

- **离地后质量估计不再"卡死"。** 旧配置下,约 7% 的飞行在离地后质量估计一直贴着下界,
  惯量兜底无法交接,内环长期过增益、持续振荡,原因是电机数据点采样造成的混叠。
  改为区间平均、并加入越界重锚后,在 64 轮预注册配对实验里,吊起段贴下界的帧占比
  从 **24.5% 降到 3.2%**(p < 0.001),发散也没有增加。
- **整轮安全测试 12/12 通过**(正常投放、指令后延迟 4 秒脱离、卡住不脱、无指令意外脱落,
  各 3 轮):
  - 没有一次在箱子还挂着时提前清除载荷模型;
  - 卡住时 3/3 进入未决状态并稳定悬停;
  - 意外脱落 3/3 在约 3.5 秒内被自主检出;
  - 事件后位置误差峰值 0.14–0.24 m,无发散。
- **估计精度**:带载后质量估计约 2.20 kg(真值 2.214 kg);偏心主方向估到真值的约 86%。

## 10. 局限

- 目前只有仿真结果。上真机需要改用电调的实测转速,并重新标定推力系数;推力系数误差超过
  约 5%,方法就会明显失效。
- 载荷质量和偏心只能估乘积,竖直距离 r_z 必须当作已知。
- 高机动时,一阶矩估计会被带着小幅漂移。
- 已知的边缘工况:如果在爬升途中才吸上箱子(形成超长力臂)会坠机,需要在吸附逻辑上禁止;
  新配置在投放段还需要更大样本的配对验证。
