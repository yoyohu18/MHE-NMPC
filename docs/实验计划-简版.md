# 实验计划(简版):载荷自适应 MHE–NMPC

> 本文是 [实验计划-EN.md](实验计划-EN.md) 的中文对照版。完整版(含 baseline 实现、判定规则、
> 故障注入等细节)见 [实验计划.md](实验计划.md)。

## 1. 目标

我计划检验:无人机能否估计出自身载荷的变化,并在载荷释放过程中保持稳定飞行。

系统用滑动时域估计(MHE)估计载荷参数,用非线性模型预测控制(NMPC)更新控制模型;
同时根据飞行测量确认载荷是否已经脱离,包括没有收到释放指令的情况。

实验要回答三个问题:

1. 系统能否避免在载荷实际脱离之前,就认定载荷已经没了?
2. 没有释放指令时,系统能否检测到载荷脱落?
3. 估计载荷的一阶质量矩,能否让估计更稳定?

一阶质量矩定义为 `s = 载荷质量 × 载荷水平偏心`。与单独的偏心量不同,载荷一旦离机,
它会自然归零。

## 2. 主要实验

| 实验 | 做法 | 检查什么 |
| --- | --- | --- |
| 估计器对比 | 用同一份飞行数据回放,分别跑"只估质量"、"质量 + 偏心"、"质量 + 一阶矩"三种估计器。 | 估计精度、释放后的稳定性、计算耗时。 |
| 延迟或失败的释放 | 发出释放指令后,让载荷延迟 0、1、4 或 8 秒才脱离,或者始终不脱离。 | 控制器是否过早切换到空载模型。 |
| 无指令的载荷脱落 | 在不通知控制器的情况下让载荷脱离。 | 检测率、检测延迟、飞行稳定性。 |
| 不脱落或部分脱落 | 载荷始终挂着,或者只释放一部分。 | 误报,以及错误地判定"已空载"。 |
| 鲁棒性 | 加入推力模型误差、电机转速测量误差和风扰。 | 系统在哪些条件下仍然可靠。 |

先从悬停和直线飞行做起;基础实验稳定可靠之后,再做转弯和更快的飞行。

## 3. 对比方法

| 方法 | 释放的处理方式 |
| --- | --- |
| 只看指令 | 一发出释放指令就认定已释放。 |
| 指令 + 证据 | 发出指令后才开始检查物理证据。 |
| 本文方法 | 持续检查物理证据,即使没有指令。 |
| 本文方法去掉一阶矩证据 | 检验一阶矩证据能否防止错误地确认释放。 |

前三种方法尽可能使用相同的估计器和控制器设置,让对比集中在"释放怎么处理"这一点上。
仿真中另设一个使用真实脱离时刻的方法,作为理想参考;另外再与一个标准的变化检测器,
在相近的误报率下做比较。

## 4. 记录的指标

每次实验记录:

- 在实际脱离之前错误切换到空载模型的次数;
- 成功检测、漏检以及检测延迟;
- 载荷仍挂着时的误报;
- 位置误差、恢复时间、紧急悬停事件;
- 估计器或控制器的失败次数,以及计算耗时。

实际脱离时刻单独、独立地记录。失败的试验和成功的试验都会报告。

## 5. 执行计划

1. 完成各对比方法,检查数据记录是否完整。
2. 用单独的开发数据集调参,调好后冻结,再进入正式测试。
3. 在相同条件下做日志回放和重复的 PX4 仿真实验。
4. 在硬件在环或系留测试中验证关键工况。
5. 做少量真机飞行:正常释放、延迟释放、释放失败、无指令脱落。

真机的初始目标是 **0.15 kg 载荷**、**5–10 cm 水平偏心**、**悬停到 2 m/s 的飞行**。
有危险的对比工况只在仿真或受约束的测试中进行。

## 6. 预期结果

目标是说明本文方法能否避免过早确认释放、能否检测到意外的载荷脱落,以及能否保持飞行稳定。
如果无法确认释放,预期的处理方式是停止任务并安全悬停。实验结果也会揭示方法的局限。
