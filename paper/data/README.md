# Frozen paper data

This directory contains the minimal immutable log set used by
`paper/reproduce.sh` to rebuild the paper figures and verify every referenced
cohort. `SHA256SUMS` records the identity of all 711 data files.

The files are historical experimental evidence. Do not regenerate, edit, or
replace them with new simulation runs. Historical code provenance and its
limitations are documented in `paper/REPRODUCE.md`.
